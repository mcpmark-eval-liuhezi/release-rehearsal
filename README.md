# release-rehearsal
Throwaway repo for rehearsing the release workflow demo end-to-end

## Demo runbook

This is the small script we follow during the onboarding walkthrough:

1. Start with the default branch (`main`) in a clean state.
2. Kick off the manual `rehearsal` workflow from the Actions tab (`workflow_dispatch`).
3. Cut a `rehearsal/*` branch and make a small edit to this README.
4. Open a pull request into `main` and walk through the review lifecycle — draft a review, add inline comments, then discard the draft.
5. Wrap up: confirm the workflow run and the open PR are visible on the repo.
